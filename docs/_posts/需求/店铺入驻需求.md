# 五、审核通过后：店铺工作台与店铺付费项目（App）

## （一）进入条件与状态流转

| 店铺状态   | 触发条件                                            | 工作台徽章 | 商家可执行操作                               |
| :--------- | :-------------------------------------------------- | :--------- | :------------------------------------------- |
| **待激活** | 平台审核通过                                        | 待激活     | 缴纳店铺保证金、购买或续费店铺租金、激活店铺 |
| **营业中** | 保证金已缴纳 + 店铺有效期有效，商家在工作台手动激活 | 营业中     | 处理销售订单、续费店铺租金                   |

- 进入路径：App → 我的 → 商家中心；退出商家中心返回「我的」。
- 平台审核通过后通过 App 消息中心推送「审核通过」通知，点击通知进入商家中心。
- 激活店铺为必经步骤：未激活时店铺不对外展示，已发布商品也不会被客户看到和下单。

| 店铺信息卡 | 店铺ID         | 审核通过后由系统生成，不可修改                               |
| 店铺信息卡 | 经营类目       | 取入驻申请选择的经营类目                                     |
| 店铺信息卡 | 店铺有效期至   | 由已购买租金套餐的天数累计，格式 YYYY-MM-DD                  |
| 店铺信息卡 | 店铺费用       | 入口，点击进入店铺付费项目                                   |
| 待办区     | 缴纳店铺保证金 | 未缴纳时展示，含「USD 1,000.00 · 未缴纳，缴纳后才可激活店铺」，点击进入店铺付费项目 |
| 待办区     | 店铺租金续费   | 未续费时展示，含当前店铺有效期与「续费后有效期顺延」，点击进入店铺付费项目 |
| 待办区     | 激活店铺       | 未激活时展示；条件不满足时展示「待完成：未完成项」，条件满足时展示「立即激活」 |
| 功能列表   | 销售订单       | 展示待发货订单数量角标，点击进入销售订单列表                 |
| 功能列表   | 更多功能       | 商品、店铺装修、数据、财务等模块陆续开放                     |

- 待办区常驻展示，无待办事项时显示「暂无待办事项」，不整块隐藏。
- 商家点击「激活店铺」时先校验激活条件（保证金已缴、店铺有效期未过期）；不满足时以提示说明需先完成的项，不进入确认弹窗。
- 条件满足时点击「立即激活」弹出二次确认，说明「激活后店铺开始正式经营：已发布的商品会对外展示，客户可以看到并下单购买」；确认后店铺状态变为「营业中」，工作台徽章同步更新，并提示可开始上架商品。
- 保证金缴纳与店铺租金购买均在店铺付费项目内完成，完成后返回工作台，对应待办自动消失。

## （三）店铺付费项目

| 付费项目     | 金额                 | 计费周期         | 激活店铺是否必需         | 状态            | 说明                                                         |
| :----------- | :------------------- | :--------------- | :----------------------- | :-------------- | :----------------------------------------------------------- |
| 店铺保证金   | USD 1,000.00（额度） | 一次性，支持追加 | 必需                     | 未缴纳 / 已缴纳 | 保证金额度固定；已缴纳后展示可用余额与「追加保证金」入口；提供「保证金规则」说明入口 |
| 店铺租金套餐 | 见套餐表             | 按套餐天数计费   | 必需（店铺有效期需有效） | 有效 / 已过期   | 购买后店铺有效期按套餐天数顺延；展示当前店铺有效期至与当前使用套餐 |

店铺租金套餐：取店铺经营类目的套餐提供选择，和店铺后台的租金套餐购买功能一致。

- 商家点击保证金的「立即支付 USD 1,000.00」，或点击任一租金套餐的「购买」发起支付。
- 点击套餐卡片或「权益说明」打开套餐详情抽屉，展示套餐完整说明、当前店铺有效期至与购买后延长至的日期，并提供「立即购买 USD xxx」。
- 点击「购买 / 立即购买」打开确认支付抽屉，展示支付金额、所选套餐与支付方式；支付方式有 EcoCash、Visa、Mastercard，默认 EcoCash，可切换。
- 点击「确认支付 USD xxx」后进入支付结果抽屉，展示支付状态、支付金额、支付方式、支付单号，以及保证金可用余额（保证金）或店铺有效期延长至（租金）。
- 支付成功后：保证金状态变为「已缴纳」并计入可用余额（可用余额 = 保证金额度），工作台「缴纳店铺保证金」待办消失，商家仍需返回工作台手动完成「激活店铺」；店铺租金支付成功后店铺有效期按套餐天数延长，工作台「店铺租金续费」待办消失。
- 支付方式与金额口径：金额币种为 USD，保留 2 位小数（如 USD 1,000.00）；店铺有效期按自然日累加。
- 「追加保证金」、「保证金规则」、「购买记录」为入口占位，点击仅提示待补充。

## （四）与其他模块的关系

- 与商户端 PC 的口径：付费项目对齐商户端 PC「店铺设置 → 平台合作」的店铺保证金（USD 1,000.00）与店铺租金套餐 4 档；同一店铺的保证金缴纳状态与店铺有效期必须为同一份数据，需明确在任意端缴纳后另一端同步，避免重复缴纳或有效期不一致。
- 与入驻流程的衔接：店铺信息（店铺 Logo、店铺名称、店铺ID、经营类目）来自入驻申请，平台审核通过后才进入本流程；审核未通过或商家撤回时不进入商家中心。
- 与店铺经营有效期到期与续费：工作台「店铺有效期至」与「店铺租金续费」待办与该需求共用有效期口径（见 1.25 需求：https://www.yuque.com/liujiong-xqbo3/yzlmall/oun56c2g84voz698）。
- 与销售订单：激活店铺后方可处理销售订单，当前商家中心仅开放「销售订单」一个功能模块。
