# 需求描述：

多件折模块，需要实现单独的购物车、结算。

多件折模块页面整体分为了三个部分：

1.顶部：活动列表以及折扣标签

2.中间：对应的活动商品列表

3.底部：购物车面板

## 接口

接口文档地址：https://app.apifox.com/project/5590637 接口目录ID：96365709

许多接口应该是原接口进行的改造，可能定义在旧的接口文档 D:\project\frontend-app\config\config.js 或者新维护的 D:\project\frontend-app\apis 中。

可参考的加购： 

店铺加购：D:\project\frontend-app\components\themes\shoptheme6.vue

项目级购物车 tabbar：D:\project\frontend-app\pages\cart\cart.vue

## 活动商品列表

需要添加数字步进器，允许进行加减

步进器中间展示的数量，初始化的数据来自购物车列表中匹配到的对应的商品的已加购数量



## 购物车面板

展示加购的全部数量、去结算按钮

点击加购面板，弹出购物车列表弹窗，弹窗中展示购物车列表、合计金额、立即结算按钮;购物车列表中展示商品图片、名称、金额、步进器（和活动商品列表中的步进器一致）。
