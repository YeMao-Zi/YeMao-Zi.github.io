 一、概述

LULUFULO Mart 支持多国分站运营，各分站所在国家有不同的法定节假日。平台统一配置各分站的法定节假日数据，商家根据自身经营情况，设置每个节假日是否营业。节假日数据影响买家下单时的预计配送时间计算和到店自提预约。

分为两个端：

平台管理端：配置各分站的法定节假日列表

商户端：查看平台节假日数据，设置每个节假日是否营业

 二、平台管理端 - 节假日配置

 2.1 配置入口

平台管理端 > 系统设置 > 分站管理 > 设置 > 节假日管理

进入路径：

在分站管理列表页，找到目标分站，点击「设置」

在弹出的设置弹窗中，切换到「节假日管理」标签页

 2.2 页面布局

左侧：年份筛选下拉框（默认当前年份），可按年筛选节假日列表

右侧：+ 新增 按钮和「批量导入」按钮

下方：节假日卡片列表，按开始日期升序排列

 2.3 节假日字段

| 字段     | 类型     | 必填 | 说明                                         |
| -------- | -------- | ---- | -------------------------------------------- |
| 节日名称 | 文本     | 是   | 节假日的名称，如「独立日」「英雄日」         |
| 日期     | 日期范围 | 是   | 开始日期和结束日期，单日假期起止日期相同即可 |
| 说明     | 文本     | 否   | 补充说明，如「全国法定」                     |

 2.4 新增节假日

点击「+ 新增」按钮，弹出新增弹窗

填写节日名称（必填）、选择日期范围（必填）、填写说明（选填）

点击确定保存，新增的节假日出现在列表中

 2.5 编辑节假日

点击节假日卡片右侧的「编辑」按钮

弹出编辑弹窗，可修改节日名称、日期范围、说明

点击确定保存修改

 2.6 删除节假日

点击节假日卡片右侧的「删除」按钮，确认后删除该节假日。

 2.7 批量导入

点击「批量导入」按钮，弹出批量导入弹窗

在文本框中按格式输入节假日信息，每行一个：

1.英雄日，2026-01-01 ~ 2026-02-02 ，备注信息

2.青年日，2026-01-01 ，备注信息

格式说明：

每行一个节假日，名称、日期之间用逗号（中英文均可）分隔

日期支持 YYYY-MM-DD 格式

日期范围用 ~ 分隔，如 2026-01-01 ~ 2026-01-03

不写 ~ 则为单日假期

备注可选，不填默认为「全国法定」

系统校验每行格式：

必须包含节日名称和日期

日期格式必须为 YYYY-MM-DD

结束日期不能早于开始日期

校验不通过时一次性展示所有错误行号，不做部分导入

校验通过后，所有节假日追加到当前分站

 2.8 年份筛选

下拉框自动从已有节假日数据中提取年份列表

默认选中当前年份

年份按倒序排列

切换年份即时过滤下方卡片列表

 三、商户端 - 节假日营业设置

 3.1 配置入口

商户端 > 店铺管理 > 店铺设置 > 物流方式 > 节假日营业设置

 3.2 数据来源

节假日数据由两部分组成：

平台法定节假日：来自平台管理端配置的该分站法定节假日列表，商家不可编辑或删除

商户自定义节假日：商家可根据自身经营情况自行添加，支持编辑和删除

两部分数据合并后按开始日期升序排列展示。

 3.3 页面布局

顶部提示文字：说明操作方式

右侧批量操作按钮：

「全部开启」：一键将所有节假日（含自定义）设为营业

「全部关闭」：一键将所有节假日（含自定义）设为休息

「+ 添加节假日」：弹出新增弹窗，添加自定义节假日

当前为全开/全关状态时，对应按钮高亮（默认全关）

下方：节假日卡片列表，按开始日期升序排列

 3.4 节假日卡片样式

卡片为两行布局：

| 第一行（左） | 第一行（右） | 第二行          |
| ------------ | ------------ | --------------- |
| 日期范围     | 营业 / 休息  | 节日名称 + 标签 |

单日假期：1月18日

多日假期：1月1日 ~ 1月3日

营业状态：点击卡片切换，绿色徽章「营业」/ 红色徽章「休息」

营业时卡片为蓝色浅底，休息时为灰色浅底

标签紧跟节日名称后（同行内联）：

平台节假日：灰色「法定节假日」标签

商户自定义：橙色「自定义」标签，卡片虚线边框

商户自定义卡片 hover 时显示「编辑」「删除」链接

所有节假日默认状态为「休息」

 3.5 操作说明

 切换单个节假日

点击任意假日卡片（平台或自定义），切换该节假日的营业状态（营业 ↔ 休息）。切换即时生效，卡片样式和徽章同步更新。

 批量操作

点击「全部开启」：所有节假日（含自定义）设为营业状态

点击「全部关闭」：所有节假日（含自定义）设为休息状态

 添加自定义节假日

点击「+ 添加节假日」按钮，弹出新增弹窗

填写节日名称（必填）、选择日期范围（必填）

点击确定保存，新增的节假日以橙色「自定义」标签和虚线卡片样式展示

新增的节假日默认「休息」，与其他节假日一起参与批量操作

 编辑 / 删除自定义节假日

hover 自定义节假日卡片，右侧显示「编辑」「删除」链接

编辑：弹出编辑弹窗，可修改节日名称和日期范围

删除：确认后删除该自定义节假日，不可恢复

平台法定节假日不显示编辑和删除操作

 四、业务影响

 4.1 客户端 - 可预约提货日期

客户在客户端选择到店自提时，系统根据商家的自提配置计算可预约的提货日期范围。计算过程中，商家设置为「休息」的节假日日期需要自动剔除，并向后顺延补足相应天数。

 计算逻辑

系统根据商家配置的物流设置，计算客户可预约提货的起止日期（参考「商户端 - 物流设置」中的自提配置）

遍历该日期范围内的每一天，检查是否命中商家设置为「休息」的节假日

命中的日期从可选列表中剔除

因剔除导致可选日期减少，将结束日期向后顺延相同天数，补足可选日期数量

新顺延的日期同样需要经过节假日检查，若再次命中则继续顺延

 示例

假设商家配置：客户可提前最多 3 天预约提货，下单选 1 号，则原始可选日期为 1 号、2 号、3 号。

| 场景            | 节假日      | 剔除日期 | 顺延后可选日期 |
| --------------- | ----------- | -------- | -------------- |
| 无节假日        | 无          | —        | 1号、2号、3号  |
| 3号为节假日     | 3号休息     | 3号      | 1号、2号、4号  |
| 2号~3号为节假日 | 2号~3号休息 | 2号、3号 | 1号、4号、5号  |

 多商家场景

同一分站的不同商家可对同一节假日设置不同的营业状态：

商家 A 在独立日营业 → 该商家的客户可在独立日预约提货

商家 B 在独立日休息 → 该商家的客户不可在独立日预约提货

 4.2 订单处理

节假日不影响已生成订单的履约时间计算

仅影响用户下单时对未来提货日期的预估

 4.3 分站关停

分站关停时，该分站的节假日数据保留，不作删除

商家端不再展示该分站的节假日信息

 五、示例场景

津巴布韦站（ZW001）2026 年法定节假日：

| 节日名称   | 日期范围                | 说明     |
| ---------- | ----------------------- | -------- |
| 新年假期   | 2026-01-01 ~ 2026-01-03 | 全国法定 |
| 青年节     | 2026-02-21              | 全国法定 |
| 复活节假期 | 2026-04-03 ~ 2026-04-06 | 全国法定 |
| 独立日     | 2026-04-18              | 全国法定 |
| 英雄日     | 2026-05-25              | 全国法定 |
| 非洲日     | 2026-08-11              | 全国法定 |
| 圣诞节假期 | 2026-12-25 ~ 2026-12-27 | 全国法定 |
| 团结日     | 2026-12-22              | 全国法定 |

某商家在圣诞节假期（12月25日27日）期间休假，将「圣诞节假期」卡片切换为「休息」。买家在该商家店铺下单时，系统将 12月25日27日从这个商家的预计配送日期中排除。



## 可用接口：

1.店铺节假日列表：
get /admin/shop/shop-store-holiday/list
无入参
返回格式：

```
/**
 * StoreHolidayListResponse
 */
export interface Response {
    code?: number;
    /**
     * 节假日列表（按开始日期升序）
     */
    data?: StoreHolidayVO[];
    message?: string;
    [property: string]: any;
}

/**
 * StoreHolidayVO，店铺节假日视图对象（平台法定+自定义合并）。source=1 为平台法定节假日，source=2 为自定义节假日。editable=true
 * 表示可编辑/删除（仅自定义）。
 */
export interface StoreHolidayVO {
    /**
     * 是否可编辑/删除（仅自定义节假日为true）
     */
    editable?: boolean;
    /**
     * 结束日期（yyyy-MM-dd）
     */
    endDate?: string;
    /**
     * 平台节假日ID（平台法定节假日）
     */
    holidayId?: number | null;
    /**
     * 店铺节假日记录ID（自定义节假日）
     */
    id?: number | null;
    /**
     * 是否营业：0-休息 1-营业
     */
    isOpen?: number;
    /**
     * 节日名称
     */
    name?: string;
    /**
     * 来源：1-平台法定 2-自定义
     */
    source?: number;
    /**
     * 开始日期（yyyy-MM-dd）
     */
    startDate?: string;
    [property: string]: any;
}
```
